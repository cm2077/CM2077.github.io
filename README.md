# 率土之滨 · 荣誉计算器

在线使用：**https://cm2077.github.io/**

《率土之滨》赛季结算荣誉值估算工具。填入赛季数据，一键算出 PVE / PVP / 成就荣誉与总荣誉，用于规划赛季目标。

## 功能

- PVE 荣誉：最高势力值、攻城灭敌、攻城拆除、占城数量
- PVP 荣誉：武勋、灭敌数（玩家兵力）、翻地数量、拆除耐久，每项带封顶进度条
- 成就荣誉：三星 / 四星 / 五星成就数量 + 其他手动补充
- 吸顶总荣誉卡片，实时显示 PVE / PVP / 成就小计
- 纯单文件 HTML，无框架、无外部依赖，可离线打开

## 计算规则（摘要）

- 势力值：≤1万部分每1万 70 荣誉，超出后每1万 35 荣誉，上限 300
- 武勋：前200万每1万 1 荣誉，超200万后每3万 1 荣誉，封顶 200
- 灭敌（玩家）：前1000万每10万 1 荣誉，超1000万每20万 1 荣誉，封顶 200
- 翻地：每5块 1 荣誉，封顶 150
- 拆除（玩家建筑）：前10万每500 1 荣誉，超10万每2000 1 荣誉，封顶 150
- 攻城灭敌：每1万 1 荣誉；攻城拆除：每100耐久 1 荣誉
- 成就：三星 10、四星 20、五星 30 荣誉

> 不同赛季/剧本规则可能存在微调，本工具为估算用途，请以游戏内赛季结算面板为准。
